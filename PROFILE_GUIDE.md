# Maintaining this profile

The public repository `m-qazi99/m-qazi99` is the GitHub profile repository. Its root README appears on [the profile](https://github.com/m-qazi99). The portfolio website has a separate repository: [m-qazi99.github.io](https://github.com/m-qazi99/m-qazi99.github.io).

## Edit

- Update `README.md` for positioning, technologies, case studies, experience and contact links.
- Update both banner SVGs for headline or brand changes. Use a text editor; there are no image-service dependencies.
- Keep project case-study links distinct from public implementation repositories.
- Add evidence-backed outcomes only when a reproducible test or other supported measurement exists.
- Move a skill out of the developing section only when the work supports it.

## Next worthwhile upgrades

No visitor counters, external statistics-image services, decorative skill percentages, fake achievements or scheduled content mutations are needed. GitHub already shows real contribution activity. This repository is a professional profile, not a personal-data analytics service.

## Design rationale and references

Reviewed October 19, 2026. This is an original implementation informed by readable structure and evidence presentation, not a copy of another person's branding or claims.

- [GitHub: Managing your profile README](https://docs.github.com/en/account-and-profile/how-tos/profile-customization/managing-your-profile-readme) — exact repository naming, public visibility and root README requirements.
- [Alexey Grigorev's profile README](https://github.com/alexeygrigorev/alexeygrigorev) — concise identity and direct links to concrete work.
- [Arthur Graf's data/AI profile](https://github.com/arthurmgraf/arthurmgraf) — capability grouping, experience and featured project summaries. Other people's metrics and proficiency are not evidence for this profile.
- [Kamalakar Karpeta's data engineering profile](https://github.com/kamalakarpeta/kamalakarpeta) — clear platform focus, project progression and a distinction between established work and exploration.

No objective ranking of these profiles as “best” is claimed. Selection focused on relevant presentation patterns. All professional claims here use the already-published portfolio and its résumé baseline; no new experience or certifications were added.
