# Visual profile redesign

Reviewed 19 October 2026. The uploaded reference is Emma Bostian's large directory of developer portfolio websites. This redesign uses a focused sample; it does not claim to audit all 2,000+ listed sites.

| Reference | Observation | Applied decision |

AnuragHazra's profile could not be retrieved in this review; no current visual conclusions are drawn from that page.

## Original implementation

- White/champagne graphic surfaces with gold accents, soft lavender background detail, and original data-platform illustrations.
- Image-led README replaces repeated prose, tables, instructional headings, and the previous workbench/atlas terminology.
- Eight actual technology logos: Azure, Python, Apache Spark, SQL Server, MySQL, Git, Azure DevOps, Streamlit. Each tile links to the product's documentation or official website.
- Portfolio, résumé, LinkedIn, and email image buttons.
- Three illustrated cards link to existing case studies. The knowledge assistant remains explicitly a proof of concept. These are not represented as three public code repositories.
- Compact Cognizant career graphic links to full experience details.
- Professional content remains available on the portfolio website; alt text supplies equivalent short descriptions to assistive technology.

## Asset provenance and maintenance

All layout, illustration, card, and banner SVGs are original and generated by `scripts/build_visual.py`. Technology-logo SVGs come from the [Devicon project](https://github.com/devicons/devicon); its license is retained at `assets/visual/DEVICON-LICENSE.txt`. Brand marks belong to their respective owners. No reference profile's personal achievements, source code, banners, or screenshots were copied.

GitHub README images support links, while custom page JavaScript is not embedded in the README. The website supplies search, filters, and live scenario selection.
